# Dependencies

## Core library

- A C++17 compiler
- The compiler-provided C++ standard library
- No third-party source or runtime dependency

## Tests

- CMake `Threads` resolves compiler or platform thread support
- No external test framework

## Optional Windows Dashboard

- Windows SDK, Win32, and GDI
- Build-time and system dependency only
- No redistributed third-party library

Build configuration requires CMake 3.22 or newer.
