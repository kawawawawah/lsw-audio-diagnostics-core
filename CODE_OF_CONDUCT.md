# Code of Conduct

Contributors are expected to be respectful, constructive, and welcoming. Harassment, discrimination, threats, and personal attacks are not acceptable. Report concerns privately to the project maintainer; reports will be handled with appropriate discretion.

This project follows the spirit of Contributor Covenant version 2.1. The official text is available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
